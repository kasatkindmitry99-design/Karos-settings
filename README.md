# Karos-settings

Приготовление теста. Сахар-песок, яйца, сметану, двууглекислый нат-рий, углекислый аммоний перемешивают в течение 20-30 мин до получе ния однородной массы. Затем добавляют муку и продолжают замес теста

18

не более 1-2 мин. Дальнейшее приготовление производят так же, как в рец. № 8 (полуфабрикат песочный).
